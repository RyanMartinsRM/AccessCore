AccessCore

Sistema Inteligente de Gestão de Controle de Acesso

Versão 1.0.0 (Beta Acadêmico)

👥

Gestão de Identidades

O AccessCore vai além de um simples cadastro. O módulo de gestão de usuários permite a criação de perfis detalhados para Moradores, Visitantes e Prestadores de Serviço. Cada perfil possui regras de negócio específicas, garantindo que os dados estejam sempre organizados e acessíveis para a operação de portaria.

📟

Integração de Hardware

Desenvolvido para ser agnóstico a fabricantes, o sistema suporta integração com as principais marcas do mercado, como ControlID, Hikvision e Intelbras. O gerenciamento centralizado permite monitorar o status online/offline dos dispositivos em tempo real, facilitando a manutenção preventiva.

🛡️

Segurança e Níveis de Acesso

A segurança é granular. O sistema permite a criação de "Níveis de Acesso" personalizados, definindo exatamente quais portas ou catracas cada grupo de usuários pode acessar. Isso impede, por exemplo, que um visitante acesse áreas restritas da administração ou que prestadores entrem fora do horário comercial.

📊

Relatórios e Auditoria

Rastreabilidade total. Todas as ações no sistema, desde um login de operador até a abertura de uma porta, são registradas em logs imutáveis. O módulo de relatórios oferece uma visão clara do fluxo de pessoas, essencial para tomadas de decisão e investigações de segurança.

⚙️

Customização Dinâmica

Cada ambiente é único. O AccessCore possui um painel administrativo que permite alterar a nomenclatura do sistema (ex: mudar "Morador" para "Aluno"). Isso torna o software versátil para atender condomínios residenciais, escolas, empresas corporativas ou indústrias.

🌗

Experiência do Usuário (UX)

Com uma interface moderna e responsiva, o sistema foi projetado pensando no conforto do operador. Inclui suporte nativo a Modo Escuro (Dark Mode) para reduzir a fadiga visual durante turnos noturnos e feedback visual instantâneo para todas as ações.

Tecnologias Utilizadas

Este projeto foi desenvolvido aplicando conceitos de Engenharia de Software, Banco de Dados e Desenvolvimento Web Moderno.

Python 3 Flask Framework SQLAlchemy (ORM) SQLite / SQL Server HTML5 & CSS3 JavaScript (ES6) Chart.js
